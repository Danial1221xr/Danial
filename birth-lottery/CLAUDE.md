# Лотерея рождения

Браузерная игра-симуляция жизни по мотивам «1 из 8 миллиардов» (https://1in8b.life/ru/). Игрок рождается случайным ребёнком в одной из 172 стран (с вероятностью по реальной статистике рождений) и проживает его жизнь год за годом до смерти.

Автор проекта — Даниал (Казахстан). Общение и весь интерфейс игры — на русском.

## Цель и план

1. **Сделано:** веб-версия с реальными данными 172 стран, выборами, мечтой с ИИ и графикой.
2. **Дальше:** миры «Прошлое»/«Будущее», PWA, детальный режим по Казахстану и Центральной Азии (области, город/село).
3. **Потом:** мобильное приложение для iPhone и Android (Expo/React Native или Capacitor поверх веб-версии; App Store ≈$99/год, Google Play ≈$25 разово; рейтинг 16+/17+ из-за тем смерти и насилия).

## Структура

Без сборщиков, чистый JS. Данные грузятся через `fetch`, поэтому игру открывают через локальный сервер (`python3 -m http.server` в папке игры), а не двойным щелчком.

- `index.html` — разметка экранов «Старт», «Жизнь», «Конец», «Мемориалы», набор SVG-иконок для нити жизни.
- `css/style.css` — дизайн. Все цвета — токены в `:root` (светлая тема) и в двух тёмных блоках (`prefers-color-scheme` и `[data-theme="dark"]`): фазы жизни `--ph-*` (палитра проверена валидатором dataviz на контраст и различимость при дальтонизме), карта `--map-*`, сцены `--scene-*`, одежда `--cloth-*`; кожа `--skin-1…6`, волосы `--hair-*` и `--face-ink` одинаковы в обеих темах.
- `js/engine.js` — движок, **не трогает DOM**: UMD-модуль (`window.LR.engine` в браузере, `module.exports` в Node). Данные подключаются через `setData(countries, names, cal)`.
- `js/ui.js` — интерфейс: экраны, лента, модальные окна, цикл времени, мемориалы, мечта.
- `js/ai.js` — клиент ИИ (ходит только к своему Worker'у), `js/config.js` — адрес Worker'а `AI_ENDPOINT` (пусто = шаблоны).
- `js/map.js` — карта мира и вспышки рождений, `js/portrait.js` — процедурный портрет и сцены этапов жизни, `js/charts.js` — графики экрана конца.
- `data/countries.json` — 172 страны (генерируется, руками не править), `data/world-timeline.json` — прогноз ООН по миру на 2024–2100 (`tools/fetch-world.js`), `data/names.json` — имена по языковым группам, `data/cal.json` — поправки калибровки, `data/world.json` — контуры стран для карты, `data/comparison-prototype.md` — сверка старых цифр прототипа с источниками.
- `tools/` — `fetch-data.js` (сбор данных), `country-meta.js` (русские названия, регионы, группы имён — правится вручную), `lib/rdata.js` (читатель .rda ООН), `calibrate.js` (калибровка), `build-map.mjs` (сборка карты), `load-engine.js` (движок + данные для Node), `calibration-report.txt` (последний отчёт). Зависимости только для инструментов: `cd tools && npm install`.
- `worker/` — Cloudflare Worker для ИИ (см. ниже), со своими тестами.
- `tests/engine.test.js` — тесты движка. Все тесты: `node --test` из папки игры.

## Данные

`node tools/fetch-data.js` собирает `data/countries.json`. 172 страны = 174 крупнейших по населению страны и территории из UN WPP без Реюньона и Западной Сахары; они покрывают больше 99% рождений в мире. У каждой цифры в поле `src` — источник (`wpp`, `wdi`, `bl`, `whr`, `gapminder`, `region`), год и пометка `est: true` для оценок.

- UN WPP 2024 (R-пакет ООН `PPgp/wpp2024`, bzip2 + R-сериализация): рождения, население, LE мужчин и женщин, год 2023.
- World Bank WDI: по умолчанию через зеркало Gapminder `open-numbers/ddf--open_numbers--world_development_indicators` на GitHub, с `--official` — через api.worldbank.org (этот режим в облачной среде разработки не проверялся: хост закрыт сетевой политикой).
- Barro–Lee v3 (годы учёбы 25–64 лет, 2015), World Happiness Report через Gapminder, Gapminder как запасной источник ВВП и детской смертности (Тайвань, КНДР, Куба, Эритрея, Йемен, Венесуэла).
- Пропуски: сначала устаревшее значение (с 2000 г., помечено оценкой), затем среднее по региону, взвешенное по населению. Детские браки и ВИЧ, если в регионе нет данных совсем, — 0.
- Поля страны: `births` (тыс./год), `pop` (млн), `leM`, `leF`, `imr`, `u5`, `gdp` (ВВП на душу ППС), `gini`, `school`, `tert`, `agri`, `fert`, `mmr`, `hiv`, `hom`, `smoke`, `sat`, `cm`, `urb`; плюс `region` (SA, EA, SSA, ME, LA, EE, CA, HI) и `names` (группа имён).

## Как устроен движок

- **Смертность** — `baseQ`: возраст 0 из младенческой смертности, 1–4 из детской, с 5 лет закон Гомпертца–Мейкхема; параметр подбирается бинарным поиском (`getTable`) под LE страны и пола.
- **Личный множитель риска** (`Life.mult`) — богатство, курение, алкоголь, стресс, спорт, болезнь, фокус года, забота детей, события года (`yearRisk`). Курение и алкоголь нормированы на долю в стране, чтобы средний риск не уезжал. Поверх — поправка `CAL[страна][пол]` с 5 лет.
- **Доход** — логнормальный: `σ = √2 · Φ⁻¹((G+1)/2)`, среднее = ВВП ППС × 0,55 × `CAL.ki`. `zf` — семья при рождении, `zp` — личный доход, `shock` — временные удары. `CAL.zb` центрирует `zp`, `CAL.ki` подгоняет средний доход взрослых к ВВП ППС × 0,55.
- **Сельские жители** — по урбанизации ООН (`ruralShare`), сельскохозяйственная работа — по доле занятых в с/х среди сельских.
- **Цикл года**: `beginYear()` → решения (у каждого варианта `fn` и вес `w` для авторежима и соседей) → UI показывает их по одному → `endYear()` разыгрывает события → возраст +1, запись в `incomeLog`.
- **Решения**: базовые (уход из школы, вуз, брак, где рожать, эмиграция по `DEST`, переезд в город, бросить курить, лечение) + таблица `DECISIONS` (28 решений по этапам жизни: детство, юность, взрослость, старость). Новых решений — не больше двух в год. У каждого есть `ages:[от, до]`, по ним строится индекс по возрасту (иначе симуляция в разы медленнее).
- **События**: таблица `EVENTS` (25 событий: привычки, урожай/засуха, кризис, эпидемия, инфляция, бедствие, наследство, травма, внуки, ограбление, повышение, своё дело, долги, жильё, стипендия, пенсионная реформа и др.), вероятности — из статистики страны и прошлого человека.
- **Курение и алкоголь — не выбор, а последствие**: события `smokeStart`/`drinkStart` с вероятностью из статистики (курение по полу, `DRINK` по регионам), которую сдвигают компания, армия, ранняя работа, стресс, развод, спорт, фокус «Здоровье». Решений «начать курить/пить» нет и быть не должно (это проверяет тест); есть только «Бросить курить» и «Пить меньше» по совету врача.
- **Армия** — `DRAFT`: доля призываемых по странам с призывом и срок службы.
- **Мечта** (этап 3): в 10 лет решение `dream` с `input: true` (свободный текст или вариант). Профиль `{sphere, edu, needUni, needMove, difficulty}` даёт ИИ или `classifyDreamLocal` (ключевые слова, `SPHERES`, `DREAM_HARD`). Развилки в 14–16, 22–25 и 35–45 лет: текст от ИИ или `forkTemplate`, варианты с `kind` (study, move, risk, safe, network, money, give_up). **Шанс считает только `dreamChance`** — трудность, вузы и ВВП страны, достаток, образование, прошлые успехи. Итог `dreamOutcome()`: сбылась / частично / жизнь пошла иначе / не успела.
- **Показатели 0–100** (этап 5): здоровье (`health()` — риск умереть в этом году против ровесника в Японии плюс возраст; личная часть — `hp` в `mult`), знания (`know`: учёба, работа, книги, курсы; влияют на поступление, доход, повышения и шансы мечты), счастье (`happy()`: удовлетворённость жизнью в стране + настроение `mood` − стресс; несчастье добавляет стресс), отношения (`rel`: семья и друзья; влияют на брак, кризисы в браке). Достаток — процентиль дохода в стране, плюс `worldIncomePctl` — среди всех людей мира. Все поправки — через `L.adj({mood, rel, know, hp, stress, shock})`.
- **Повседневная жизнь**: `DAILY` (55 обычных событий: родители поругались, наругали за двойку, питомец, отпуск, внуки…) — не больше одного в год, выбор по весам `w(L,x,c)`; `CHOICES` (22 бытовых выбора: двойка в дневнике, прогул, чужой кошелёк, друг просит в долг, переработки, обследование, лотерейный билет…) — примерно раз в 3–6 лет. В подсказке варианта — что изменится (↑/↓) и шанс, если он есть. Выбор по весам — `pickWeighted` без лишних массивов (симуляция крутит его миллионы раз).
- **Мир** (`makeWorld`): один на всех, кто родился в одну секунду (UI создаёт его и отдаёт игроку и соседям). Постоянная часть — прогноз ООН (`data/world-timeline.json`, `tools/fetch-world.js`: рубежи населения, пик, смертей больше рождений, продолжительность жизни) и большой спорт; случайная — кризисы, пандемии, жара, технологии, лениво по годам с зерном. Кризис и пандемия реально бьют по доходу и здоровью.
- **Мировая статистика**: `cohortSurvival(age)` — доля доживших среди всех детей мира одного года рождения («Ваше поколение»), `incomeIn(c, z)` — доход на том же месте в обществе в другой стране («Параллельные жизни» в конце), `L.zMean()` — среднее положение во взрослой жизни.
- **Причина смерти** — `pickCause`: внешние причины пропорционально реальным частотам, иначе болезни по возрасту с поправкой на регион.
- **Соседи по секунде** — `simulateFull` прогоняет 4 жизни заранее и хранит снимок на каждый год (со статусом и фазой жизни).
- **Для графики**: `L.marks` (ключевые события для иконок нити), `L.incomeLog` (доход, средний по стране и фаза на каждый год), `L.phase()`.

## ИИ (worker/)

- Cloudflare Worker: `/dream`, `/fork`, `/epilogue`, `/health`. Провайдер — `PROVIDER` (gemini | anthropic | deepseek), модель — `MODEL` (по умолчанию gemini-2.5-flash, claude-haiku-5-5, deepseek-chat). Ключи — **только** секреты (`wrangler secret put GEMINI_API_KEY` и т. д.), в коде страницы их нет.
- Защита: CORS по `ALLOWED_ORIGINS`, Rate Limiting binding `RATE_LIMITER` (8/мин с IP) + запасной лимит в памяти, ввод ≤ 200 символов, тело ≤ 4 КБ, словарный фильтр на входе и выходе, safety settings модели, structured output (JSON-схемы в `src/schemas.js`) и проверка ответа, `soft` в промпте и фильтре.
- ИИ пишет только тексты. Шансы, исходы и эффекты — движок. Любой сбой (нет адреса, 429/503, таймаут, неверный JSON, «опасный» текст) → шаблоны; после лимита клиент выключает ИИ на 10 минут.
- Перед отправкой мечты игрок видит, куда уйдёт текст (провайдер берётся из `/health`).
- Пошаговая настройка — в README, раздел «ИИ: мечта в 10 лет».

## Правила

- **Калибровка.** После любой правки данных, `baseQ`, `mult`, формул дохода, решений или событий: `node tools/calibrate.js` (≈30–45 мин на 4 потоках; `--start 8000 --iter 2 --n 20000` дошлифовывает уже близкие поправки, `--check` только проверяет). Цель: средний возраст смерти ≈ LE − 0,5 по каждой стране и полу (шум выборки при 20 000 жизней ≈ ±0,2, у худшей из 344 групп ≈ 0,5), средний доход взрослых ≈ ВВП ППС × 0,55 (±5%). Отчёт пишется в `tools/calibration-report.txt`.
- **Тесты.** `node --test` из папки игры: данные, источники, таблицы смертности, каждая страна доживает до конца, любой выбор не ломает жизнь, все решения и события встречаются, мечта, Worker с подменённым ИИ.
- **Тяжёлые темы.** Смерть, насилие и самоубийство — только фактом, без подробностей, рядом ссылка на помощь (`HELP`: findahelpline.com, 112). Режим `soft` заменяет насильственные причины на «внешняя причина» и действует на тексты ИИ (промпт + фильтр в Worker'е и в `js/ai.js`). Игра от 15 лет.
- **Хранение.** Мемориалы и настройки — `localStorage` (ключи `lr.*`), все обращения в try/catch.
- **Вёрстка.** Телефон 390 px без горизонтальной прокрутки, светлая и тёмная тема, только токены из `:root`, `prefers-reduced-motion` выключает анимации и вспышки (карта становится неподвижной). Проверять Playwright-скриншотами.
- **Внешний вид.** Не копировать название, логотип и дизайн оригинала. Повторяется только механика.

## Чего ещё нет

- Миры «Прошлое» и «Будущее» (кнопки отключены).
- Музыка, публичные мемориалы, «случайная чужая жизнь» (нужен сервер).
- Режим «Для уроков», PWA (manifest, иконки).
- Живой вызов ИИ проверен только с подменёнными ответами (ключа в среде разработки не было); `fetch-data.js --official` не проверен по той же причине (сеть).
