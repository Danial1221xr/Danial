# Лотерея рождения

Симуляция жизни: вы рождаетесь случайным ребёнком (страна выпадает по реальной статистике рождений) и проживаете его жизнь год за годом.

## Запуск

Сборка и установка не нужны, но данные стран лежат в отдельных JSON-файлах, поэтому игру нужно открывать через локальный сервер (двойной щелчок по `index.html` не сработает — браузер не даст загрузить `data/*.json`):

```
cd birth-lottery
python3 -m http.server 8000      # или: npx serve .
```

и откройте http://localhost:8000.

## Структура

- `index.html` — разметка экранов.
- `css/style.css` — дизайн, цветовые токены светлой и тёмной темы.
- `js/engine.js` — движок без DOM (работает и в браузере, и в Node).
- `js/ui.js` — интерфейс.
- `js/ai.js`, `js/config.js` — клиент ИИ и его настройки.
- `js/map.js`, `js/portrait.js`, `js/charts.js` — карта мира, процедурный портрет со сценами этапов жизни, графики экрана конца.
- `data/world-timeline.json` — прогноз ООН по миру (население, рождения, продолжительность жизни до 2100 года) для новостей «Мир», собирается `node tools/fetch-world.js`.
- `data/countries.json` — статистика стран, `data/names.json` — имена, `data/cal.json` — поправки калибровки, `data/world.json` — карта (Natural Earth 1:110m, собирается `node tools/build-map.mjs`).
- `worker/` — Cloudflare Worker для ИИ.
- `tools/` — калибровка и сбор данных, `tests/` — тесты движка.

## Работа с Claude Code

1. Установите Claude Code: https://docs.claude.com/en/docs/claude-code/overview
2. В терминале перейдите в папку проекта и запустите:

   ```
   cd birth-lottery
   claude
   ```

3. Claude Code сам прочитает `CLAUDE.md`, где описаны контекст, устройство движка и план.

## Калибровка и тесты

После изменения данных стран или правил симуляции запустите:

```
node tools/calibrate.js          # пересчитать data/cal.json
node tools/calibrate.js --check  # только проверить отклонения
node --test                      # тесты движка
```

## Данные стран

`data/countries.json` собирается скриптом `tools/fetch-data.js` из открытых источников (172 страны, у каждой цифры — источник и год в поле `src`, оценки помечены `est: true`):

- UN World Population Prospects 2024 — рождения, население, продолжительность жизни (R-пакет ООН `wpp2024` на GitHub);
- World Bank World Development Indicators — смертность детей, ВВП ППС, Джини, образование, занятость, здоровье, урбанизация (по умолчанию через зеркало Gapminder на GitHub, с флагом `--official` — напрямую через api.worldbank.org);
- Barro–Lee v3 — средние годы учёбы взрослых;
- World Happiness Report — удовлетворённость жизнью;
- Gapminder — запасной источник для стран без данных Всемирного банка (Тайвань, КНДР, Куба и др.).

```
cd tools && npm install && cd ..
node tools/fetch-data.js
node tools/calibrate.js
```

Русские названия, регионы и группы имён стран — в `tools/country-meta.js`, имена — в `data/names.json`. Сверка старых цифр прототипа с источниками — `data/comparison-prototype.md`, последний отчёт калибровки — `tools/calibration-report.txt`.

## ИИ: мечта в 10 лет

В 10 лет игрок своими словами пишет, кем хочет стать. Потом в ≈15, 22–25 и 35–45 лет жизнь подкидывает развилки, связанные с мечтой, а в конце игра подводит итог: мечта сбылась, сбылась частично или жизнь пошла иначе. **Шансы каждого варианта считает движок** — по трудности мечты, статистике страны, достатку семьи и образованию; ИИ только пишет тексты.

Без ИИ всё тоже работает: мечта разбирается по ключевым словам, развилки и итог берутся из шаблонов. ИИ подключается через ваш собственный Cloudflare Worker (папка `worker/`), чтобы ключ никогда не попадал в код страницы.

> Что уходит в ИИ: текст мечты и обобщённые данные игровой жизни (страна, достаток в процентилях, образование, занятие, подписи прошлых решений). Перед отправкой игра предупреждает игрока, что текст уйдёт в Google. На бесплатном уровне Gemini Google может использовать запросы для улучшения своих моделей.

### 1. Получить ключ Gemini

1. Откройте https://aistudio.google.com и войдите с аккаунтом Google.
2. Слева выберите **Get API key** → **Create API key** (можно в новом проекте).
3. Скопируйте ключ. Никуда его не вставляйте, кроме команды из шага 3 ниже, и не коммитьте.
4. Лимиты бесплатного уровня зависят от проекта — посмотреть их можно в AI Studio на странице **Usage / Rate limits**. Бесплатно доступны модели Flash и Flash-Lite.

### 2. Подготовить Worker

1. Заведите бесплатный аккаунт на https://dash.cloudflare.com.
2. Установите Node.js 18+ (https://nodejs.org).
3. В терминале:

   ```
   cd birth-lottery/worker
   npx wrangler login
   ```

4. Откройте `worker/wrangler.toml` и в `ALLOWED_ORIGINS` впишите адрес, откуда открывается игра, без пути и без слеша в конце, например `https://danial1221xr.github.io` (можно несколько через запятую). Запросы с других сайтов Worker отклонит.

### 3. Сохранить ключ как секрет и задеплоить

```
npx wrangler secret put GEMINI_API_KEY    # вставьте ключ, когда спросит
npx wrangler deploy
```

Wrangler напечатает адрес вида `https://birth-lottery-ai.<ваш-поддомен>.workers.dev`. Проверьте его: откройте `…workers.dev/health` — должно быть `{"ok":true,"provider":"gemini",…,"configured":true}`.

### 4. Вписать адрес в игру

В файле `js/config.js`:

```js
AI_ENDPOINT: 'https://birth-lottery-ai.<ваш-поддомен>.workers.dev'
```

Готово. Если лимит закончился или ИИ не отвечает, игра на 10 минут переходит на шаблоны и продолжает работать.

### Переключить на Claude Haiku или DeepSeek

В `worker/wrangler.toml` поменяйте `PROVIDER` и задайте ключ нужного сервиса, затем задеплойте снова:

```
# Claude Haiku (ключ: https://console.anthropic.com → API Keys)
PROVIDER = "anthropic"            # модель по умолчанию claude-haiku-5-5
npx wrangler secret put ANTHROPIC_API_KEY

# DeepSeek (ключ: https://platform.deepseek.com → API keys)
PROVIDER = "deepseek"             # модель по умолчанию deepseek-chat
npx wrangler secret put DEEPSEEK_API_KEY

npx wrangler deploy
```

Модель можно задать явно переменной `MODEL` (например, другая модель Gemini Flash). Предупреждение для игрока подстраивается под провайдера автоматически.

### Обычная жизнь от ИИ

Если ИИ подключён, он заранее (на 3–8 лет вперёд, в зависимости от скорости) пишет обычные события жизни — семейный быт, школа, друзья, работа, праздники, местные реалии — и иногда небольшой бытовой выбор (`POST /moments`). Учитываются страна, город или деревня, семья, условия в доме и недавние события, чтобы не было повторов. Последствия ИИ задаёт только метками (`mood+`, `rel-`, `money+` и т. п.), а их силу определяет движок, поэтому ИИ не может «сломать» статистику. Крупные перемены (свадьбы, дети, переезды, смерти, болезни) по-прежнему решает игра. В ленте такие события отмечены значком ✦. Без ИИ работают заготовки: их около ста, и повторы выпадают всё реже.

> После обновления игры задеплойте Worker заново (`cd worker && npx wrangler deploy`), иначе у него не будет адреса `/moments`, и игра будет брать заготовки.

### Защита Worker'а

- ключи — только секреты Cloudflare, в коде страницы и репозитории их нет;
- CORS: отвечает только сайтам из `ALLOWED_ORIGINS`;
- ограничение частоты: 8 запросов в минуту с одного IP (привязка `RATE_LIMITER` в `wrangler.toml`; если она недоступна, работает запасной лимит `RATE_LIMIT`);
- длина мечты — до 200 символов, тело запроса — до 4 КБ;
- фильтр неприемлемого текста на входе (словарь) и на выходе, фильтры безопасности модели, проверка ответа по JSON-схеме;
- режим «Убрать пугающие подробности» передаётся в промпт, а ответы со словами о смерти и насилии в этом режиме отбрасываются (и в Worker'е, и в игре).

### Проверка без ключа

```
cd birth-lottery
node --test                      # тесты движка и Worker'а (ответы ИИ подменены)
cd worker && npx wrangler dev    # локальный Worker; ключ для него положите в worker/.dev.vars: GEMINI_API_KEY=...
```
